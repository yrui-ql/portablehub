# UX 复盘与参考

> 这份文档只描述产品与交互，不包含任何本机软件名、路径或用户信息。

## 我做错了什么

1. **先写功能，后想交互**：没有状态图、没有首次使用流程、没有交互稿，直接堆功能。
2. **参考的是功能清单，不是交互范式**：我对比了同类软件的“有什么功能”，却没研究“用户怎么操作”。
3. **把“能跑”当成“能用”**：单元测试和自检只覆盖机制，没有任何可用性验收。
4. **没有设计系统**：间距、字号、层级、状态没有 token；像素风只落在边框和阴影上。
5. **没有真实操作**：点击自动化失败后，我没有改用键盘/手工脚本去走完整流程。

## 实测与代码审查发现的问题

### P0 · 直接影响使用

| 问题 | 现象 | 修法 |
|---|---|---|
| 同名重复导入 | 同一应用出现两张卡片 | 按名称去重（已修，待发布） |
| 发现扫描默认全盘 | 点击“发现”后阻塞数分钟，结果 200+ 条，绝大多数是游戏 | 先选扫描范围；默认跳过系统盘；可取消 |
| 发现结果默认全选 | 一次误点可能导入大量无关项 | 默认不选，提供全选/反选 |
| 设置页长滚动 | 没有分区导航，找不到选项 | 左侧分区导航（外观/启动/导入/目录/关于） |
| 单击即启动 | 容易误触；卡片没有选中态 | 单击选中，双击/Enter 启动 |
| 搜索无键盘导航 | 只能输入后按 Enter，不能上下选择 | ↑↓ 选择、Enter 启动、Esc 清空 |

### P1 · 明显影响体验

| 问题 | 现象 | 修法 |
|---|---|---|
| 右键菜单缺编辑 | 不能改名称/路径/参数/工作目录 | 增加编辑对话框 |
| 首次关闭无提示 | 关窗后以为退出了 | 首次关闭提示“仍在托盘运行” |
| 导入无失败明细 | 失败只有一条 toast | 结果面板：成功/跳过/失败分类，可复制 |
| 链接模式路径语义 | 配置里存的是真实目标路径 | 存链接路径，或明确标注“链接到 …” |
| 多版本 exe 选择 | 可能选中兼容模式 | 已修：优先最短匹配 |

### P2 · 打磨

- 网格/列表切换、分组、拖拽排序、最近使用
- 更多主题（至少一套现代风格）
- 首次运行引导（选目录 → 扫描 → 导入）
- 空状态/错误状态的可操作提示

## 交互规范（草案）

- **状态**：idle / hover / selected / pressed / disabled / loading / error，每种都有明确视觉
- **键盘**：`/` 搜索、`↑↓` 选择、`Enter` 启动、`Shift+Enter` 打开目录、`Esc` 清除/关闭、`Ctrl+,` 设置
- **单击**：选中；**双击/Enter**：启动；右键：动作菜单
- **发现**：选范围 → 扫描（进度 + 取消）→ 过滤（未添加/全部）→ 勾选 → 导入（进度 + 结果）
- **反馈**：所有超过 300ms 的操作必须有进度或忙碌态；失败必须可读、可复制

## 整改顺序

1. **P0 修 bug**：重复导入、发现范围/取消/不预选、设置分区、卡片选中/键盘、拼音搜索
2. **P1 交互重构**：编辑对话框、导入结果面板、首次关闭提示、链接语义
3. **P2 视觉系统**：间距/字号/状态 token，现代主题，空状态插画
4. **验收**：脚本化冒烟 + 手工清单（首次使用、发现、导入、启动、自启、托盘）
